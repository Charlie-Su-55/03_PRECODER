# Hybrid 的方向辅助 UE＋BS 和速率续训

本轮只新增一条 Hybrid G4 训练轨迹：从已经完成的 UE＋BS 联合训练
`joint10000` 末态出发，再做 10000 次更新。旧 FDMA `joint10000` 和旧
Hybrid `joint10000` 均原样保留，在全新的同一组验证输入上与新末态一起重评。
FDMA 不新增更新，也不削弱其模型、初始化或历史训练预算。

这是由机制诊断驱动的一次探索：在完整多用户和速率目标之外，直接监督
下行 CSI 的方向，检验 Hybrid 能否学到更利于干扰管理的发送表示和恢复结果。
本轮不增加 CDMA 式投影、正交约束、SNR 输入、接收机类型或 decoder 层数。
用户专属投影与正交初始化已有 CDMA／DeepJSCC-PNOMA 等先例；把图像换成
CSI 本身也不构成新的贡献。本轮没有投影新颖性或 Hybrid 必须获胜的预设。

六点均值差为 −0.671750，CI 为 [−0.754723, −0.588777]；低三点均值差为
−1.330647。15／20／25 dB 的区间跨零，不能说高 SNR 已证明 Hybrid 更好。
FDMA 仍有参考余量：真实 CSI 加同一 RZF 的六点均值为 33.091253，比当前
FDMA 高 2.431622。当前结果不支持“FDMA 已经太接近极限，所以需要削弱基线”。

保持各自预测行范数、仅用真实方向替换 `H_hat` 方向后，两臂六点差缩小至
−0.044289，CI 为 [−0.059829, −0.028748]。对应的方向 sin² 误差为 FDMA
0.001803052、Hybrid 0.002853371。这支持检验方向监督，但不能把差距变化
解释成某个百分比的速率损失已被唯一因果归因于方向误差。RZF 非线性、预测
范数和各 SNR 的残差共同参与结果。真实方向参考甚至高于真实 CSI RZF，也
说明预测范数可能充当任务表示；因此本轮不强制预测复信道的幅度等于真实幅度。

接收误差诊断也不支持只归咎于 decoder 深度。Hybrid shared 的六点均值为：

| 固定接收滤波器上的量 | 数值 |
|---|---:|
| 实际恢复误差 | 0.029706036 |
| self 分量平方 | 0.015619711 |
| cross-user 分量平方 | 0.009209137 |
| noise 分量平方 | 0.004687357 |
| CE 相关分量平方，属于另一种分区 | 0.020305998 |

这些量的尺度是 `mean_coordinate(|term|²/P_history)`，不是按实际总发送
能量归一化的 NMSE，也不是速率损失比例。self／cross-user／noise 必须连同
三个有符号交叉项才精确闭合。另一种分解中的 CE 项是
`A(G_true−G_hat)z`；它与 self／cross-user 重叠，不能作为第四项相加。
25 dB 时 shared 的 CE 项约 0.005909883，而 noise 项约 0.000099119，
表明固定接收机的误差底不能仅靠降低热噪声消除。本轮保持 CE 和接收机不变，
考察 UE＋BS 能否在这些约束下形成更适合下行任务的表示；并不声称已经修复 CE。

真实 CSI RZF、保持预测范数的真实方向 RZF 都是特权敏感性参考，不是性能
上界，也不成为部署 BS 的输入。无干扰水填充上界的六点均值约 82.400259，
非常松，其大差距不能当作可实现增益。

## 目标：保留范数自由度，监督多用户方向

对每个 MU 的 UE 与子载波，定义

\[
d(\widehat h,h)=1-
\frac{|\widehat h^{H}h|^2}
{\|\widehat h\|_2^2\|h\|_2^2}.
\]

对 UE 和子载波取均值形成每 MU 的方向损失，再对有效 batch 取均值。本轮目标为

\[
\mathcal L=-\operatorname{mean}_{\rm MU} R_{\rm complete\ 8UE}
+100\operatorname{mean}_{\rm MU,UE,tone}d(\widehat h,h).
\]

方向项对非零行的相位和幅度缩放不敏感，允许网络继续利用预测范数调节 RZF。
实现需对退化行作数值保护，并检查有限值。它直接对预测方向提供梯度；不能用
一个 detached 的“真实方向参考速率”替代，因为减去常数参考不会改变原 rate
目标的梯度。UE 梯度须穿过所选码字归一化、MAC 和原恢复链路到达发送端；
CE 参数保持冻结。

系数 100 是本轮预先固定的探索值，不是已证明最优的权重，尚未通过消融检验。
本轮不在最终验证或 test 上搜索系数、选择使 Hybrid 胜出的值。真实下行 CSI 只作既有 UE 本地源和
训练／评价标签；其他 UE 的真实 CSI、真实 UL 不作为新增 UE／名义 BS 输入。
本轮没有新增 UE SNR 条件输入；均衡六节点训练也不等于验证了未见连续 SNR。

## 最终比较怎样解释

最终必须先严格验收旧 FDMA、旧 Hybrid、新 Hybrid 三个完整模型，随后才打开
新的最终验证采样。三者使用相同 DL／UL 信道、pilot 和噪声视图；新训练改变了
Hybrid 的发送码字及其历史 prior，这些状态本身无需与旧模型相同，但全部在
评价时冻结。报告六个点及低三点、六点均值，包括负结果。

- 新 Hybrid 减旧 Hybrid：衡量“新增 10000 更新＋新目标”这一组合的变化。
- 新 Hybrid 减旧 FDMA：给出当前可达到的比较，但累计训练预算不等。
- 旧 Hybrid 减旧 FDMA：在相同新鲜输入上重现参照差距，避免跨验证集相减。

本轮没有同源、同预算的 Hybrid rate-only continuation。因此即使新 Hybrid
改善，也不能把增益单独归因于方向辅助项；若超过冻结 FDMA，也不能称为同预算
结构优越性证明。方向误差降低但速率不升、或低 SNR 改善而高 SNR 退化，都是
需要保留的有效结果，不能用挑 SNR／checkpoint／权重掩盖。

同时报告每 MU／UE 速率、CSI 误差、方向误差、期望信号／干扰、soft 恢复误差
和能量。跨 gamma 摘要先在同一 MU 内平均，再以 4 MU 为一批计算区间；六个
SNR 视图不是六倍独立信道。区间条件于固定模型和一个源训练 seed，不涵盖重新
训练的不确定性，也不构成多 seed 泛化或完整 ICC 复现声明。
